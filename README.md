# Student Management System (Core Java)

A console-based Student Management System built using Core Java.
This project allows users to manage student records with features like adding, viewing, updating, deleting students, and saving data persistently using file handling.


Features

* Add new student details
* View all students
* Update student information
* Delete student records
* Save and load data using a text file
* Menu-driven console interface


Technologies Used

* Java (Core Java)
* OOP Concepts (Classes, Objects, Encapsulation)
* Collections Framework (`ArrayList`)
* File Handling (`FileWriter`, `BufferedReader`)
* IntelliJ IDEA
* Git & GitHub

How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/navyachandhrika/student-management-system-java.git
   ```
2. Open the project in IntelliJ IDEA
3. Run `StudentManagementSystem.java`
4. Follow the on-screen menu options


Data Storage

* Student data is stored in a local text file (`students.txt`)
* File handling ensures data persistence between program runs
* The file is ignored in GitHub using `.gitignore`
